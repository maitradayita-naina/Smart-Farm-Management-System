
# Smart Farm Management System

A console-based C++17 project demonstrating object-oriented
programming concepts through crop management.

## Features
- Add cereal and vegetable crops
- Calculate and compare crop yields
- Display farming advice
- Save and load crop data
- Track crop objects
- Handle invalid input and exceptions

## Concepts Used
- Classes and objects
- Inheritance
- Constructor overloading
- Runtime polymorphism
- Operator overloading
- Abstract classes
- Static members
- File handling
- Exception handling

## Compile
g++ -std=c++17 -Wall -Wextra main.cpp -o SmartFarm.exe

## Run
.\SmartFarm.exe
